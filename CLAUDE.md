# bad-mom-podcast

Marketing / landing site for The Bad Mom Podcast (host: Vivian Glyck).

## Stack

- **Vite** (vanilla JS — no framework). Entry `index.html` → `src/main.js`,
  styles in `src/style.css`, images in `src/images/`.

## Commands

```bash
npm install
npm run dev       # local dev server
npm run build     # production build -> dist/
npm run preview   # preview the built site
```

## Notes

- `BMP_LP2/` is a **separate, self-contained git repository** (an alternate
  landing-page variant), not part of this project's tree. Work on it from inside
  that folder.
- `dist/` is build output and should not be edited by hand.
